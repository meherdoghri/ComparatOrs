Guide rapide pour nouveau utilisateur

Cette application compare les programmes S7 et 4YOU, detecte les differences et vous aide a verifier les changements.

  1. Chargez d'abord le dossier S7, puis le dossier 4YOU.
  2. Cliquez sur "Afficher les fichiers modifies de S7" pour verifier d'abord les programmes modifies dans S7.
  3. Cliquez ensuite sur "Verifier les changements S7 dans 4YOU" pour controler ces changements entre S7 et 4YOU.
  4. Selectionnez un programme a gauche pour voir les differences ligne par ligne.
  5. Utilisez les filtres de recherche pour trouver un nom ou un texte precise.
  6. Exportez les rapports avec le bouton "Exporter les rapports".
