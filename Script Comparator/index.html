Guide rapide pour nouveau utilisateur

Cette application compare les scripts shl_S7 et shl_4YOU, detecte les differences et vous aide a verifier les changements.

  1. Chargez d'abord le dossier shl_S7, puis le dossier shl_4YOU.
  2. Cliquez sur "Show Modified shl_S7" pour verifier les scripts modifies dans shl_S7.
  3. Cliquez ensuite sur "Check shl_S7 Changes in shl_4YOU" pour controler ces changements.
  4. Selectionnez un script a gauche pour voir les differences ligne par ligne.
  5. Utilisez les filtres de recherche pour trouver un nom ou un texte precise.
