Guide rapide pour nouveau utilisateur

Comparez 2 ou 3 versions d'un fichier texte en collant directement le contenu.

  1. Choisissez le mode 2 ou 3 fichiers.
  2. Collez le contenu de chaque version dans les zones texte correspondantes.
  3. Cliquez sur "Comparer" pour voir les differences.
  4. Utilisez "Verifier le delta dans V3" (mode 3 fichiers) pour verifier si les changements V1→V2 sont bien presents dans V3.
  5. Cochez les filtres pour afficher uniquement les lignes differentes.
